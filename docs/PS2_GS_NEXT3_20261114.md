## Exact alpha conversion

For every engine alpha byte, `(a * 128 + 127) / 255` equals `(a + 1) >> 1`.
For even `a = 2*k`, the division is `k + floor((k + 127)/255) = k`; for odd
`a = 2*k+1`, it is `k + 1 + floor(k/255) = k+1`. In both cases `0 <= k <= 127`.
Every production caller supplies a byte or the loop index 0..255.

The shift removes constant-division instruction sequences from AP88-to-CT32,
RGBA-to-CT32 and intensity/alpha-to-CT32 row construction. The same helper builds
the alpha-mask CLUT. Exact GS alpha values, RGB (including alpha-zero RGB),
partial transparency, texture dimensions, formats, filtering and upload packets
are preserved. No buffers, work arrays, allocations or VRAM changes are added.
This change makes no independent EE RAM or VRAM reduction claim.

classification, row-fill, packet reservation and upload-band functions. It
checks unchanged shared helpers and records source hashes. Only VU-chunk
completion and ring rotation are mocked; it does not replace the conversion
algorithm with a test implementation.

## Candidates excluded

An arbitrary <=16-color PSMT4 representation was investigated but not enabled.
It needs persistent per-image index maps and mapped variants of every
palette/light-table/tint CLUT. Even a contiguous-index-bank subset needs correct
CSA handling, CLUT-load cache identity, palette-lighting eligibility, VU TEX2
row-table state and planner footprint accounting. The current code has 33
PSMT8-specific checks across these paths. A nibble upload alone would silently
alter lighting or palette interpretation. No unverified format conversion,
downsampling or fallback reduction is included.

A packed reverse-palette hash candidate saved 1,020 bytes but was also removed.
The first measured version improved hits/rebuilds while slowing missing-color
lookups by 9.28%; a second version reduced that regression to 1.54% but slowed
rebuilds by 8.57%. The final palette hash is byte-for-byte the frozen baseline.
Those experiments remain only in `gs-next3-ee` and `gs-next3-ee-tune` build
artifacts and are not part of the shipped change.

The dedicated fixture does not exercise the historical VU0 outcode kernel. Its
known baseline-identical failure remains an integration-suite limitation; this
report does not declare that full suite entirely green. The coordinator performs
the final full-engine builds, GS readbacks, game-frame and RAM checks.
