## Приоритеты сессии (по убыванию)
1. H: GS HW-рендерер без графических багов + явно быстрее software (главный критерий пользователя). Дефект «текстуры на стенах/полах глючат» — найти измерением и исправить; паритет эффектов с OpenGL HW; VU1/DMA/батчинг/кэш VRAM; решение «HW по умолчанию?».
2. F: Lua-VM, UDMF, аддоны (меню Add-ons, addfile, автозагрузка), лимиты — каждый этап включается убиранием из `SRB2_PS2_NO` в `tools/ps2/build.py` только после теста; в конце `SRB2_PS2_NO` по умолчанию = пусто.
3. S: сеть (ps2ip/lwIP, хост/клиент, d_netfil), мастер-сервер (список + регистрация, `tools/ps2/mock_masterserver.py`), сплитскрин (software+HW), стабильность памяти, финальная сводка памяти.
4. Координатор в конце собирает единую ELF (все фичи) + HW-вариант, прогоняет 4 golden-демо и релизные замеры.

Итог агента: отчёт 1) сделано; 2) команды и числа до/после; 3) не проверено/упёрлось в эмулятор; 4) строки реестра отличий; 5) правки в чужих файлах. Сводка ≤ 25 строк.
Владение файлами — как в OPT6/OPT7 (правишь ТОЛЬКО свои; общие — точечно и в отчёт). `build.py` общий: F правит `NO_FEATURES`, S — LTO/сеть, H — только `SRB2_PS2_HW`-часть.
