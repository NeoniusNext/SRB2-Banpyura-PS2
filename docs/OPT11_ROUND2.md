## Роли раунда 2 (прежние агенты продолжают в своих worktree; перед началом: `git merge claude/lucid-mayer-1izlqe` и пересобрать)
### GEOM2 — ФРОНТ движка (реестр `PS2-HW-200..219`)
Слить стадии «BSP → стена/плоскость → полигон» в один дешёвый проход: данные, не зависящие от вида, готовятся при загрузке карты/по версии сектора (статика сегмента: линия, сторона, id текстур, pegging, высоты текстур, смещения;
статика сектора: свет, колормап, id флэтов, наклоны), а для кадра — только проверка версии (подпись сектора ≈ 10 слов, не ключ на полигон) и выдача. Устранить повторные вычисления на кадр: `R_FakeFlat`/tempsec (мемо на сектор на кадр), `R_PointToAngle64` для вершин
(кэш угла на вершину на кадр, точный алгоритм не менять), `HWR_Lighting`/`HWR_CalcWallLight` (на сектор/сторону один раз), `HWR_SplitWall`. Эталон правильности: поток полигонов, отданный драйверу, должен совпасть побитно (`-hwpolyhash`, `gm_polycmp.py`) с прежним на 4 демо + 10 карт.
Цель: фронт ≤ 1.3 М на D1, ≤ 2.2 М на D4 (мерить HWPROF/сэмплером на одной ELF с флагом A/B). Согласуй с VU2 интерфейс «готовый полигон/блок» (формат блока VU1 описан в `opt11-VU.md`).
### VU2 — ТЫЛ: партия, планировщик, драйвер (реестр `PS2-HW-220..239`)
Убрать дублирующие стадии между `HWR_ProcessPolygon` и `PS2HWD_DrawFans`: прямая выдача (item → блок VU1), **`PS2HWD_QuadHidden` (5 % кадра) заменить дешёвым**: полигон уже отсечён BSP/клиппером, нужен лишь дешёвый bbox-отсев (или вообще убрать, если VU1 отсекает бесплатно; проверить, что картинка и охват не меняются),
планировщик текстур (`plan_measure`/`plan_part` ≈ 0.4 М D1, 0.6 М D4): решение «уровень/CLUT/слот» мемо по (текстура, вариант, грубая плотность) на кадр; `PS2HWD_PalLit`/`vu_key_make`/`begin_draw_inner`: ключ плана один раз на партию; сортировка (`HWR_GroupSort32`/`RadixSort32`): подсчётом по id текстуры без сравнений;
`memcpy` полигонов в чанк. Цель: тыл ≤ 1.3 М на D1, ≤ 2.5 М на D4. Картинка: сравнение кадров EE-путь/VU1 и со снимками ПК (как раньше), 0 регрессий воды FX.
### FX2 — СПРАЙТЫ/ТЕНИ/HUD/НЕБО/ВОДА НА EE: скорость (реестр `PS2-HW-240..259`)
D1: ≈ 530 спрайтов на кадр — `HWR_AddSprites/ProjectSprite/SortVisSprites/DrawSprite/DrawDropShadow` ≈ 1.2 М; HUD 175 полигонов (`hw_DrawPolygon` одиночные); `hw_RenderSkyDome` 141 К; `water_sweep` 172 К (D1), `emit_cuts` 206 К (D4).
Идеи: проекция/отсев спрайтов пачкой (VU0 макрорежим или плотный цикл без double/libm), тени спрайтов одной сеткой/без отдельного планировщика, HUD в один чанк, небо кэшировать (не пересчитывать геометрию купола при тех же `viewangle`-независимых частях), вода: остаток на EE (112 полигонов/кадр в D4) на VU1.
Правило FX сохраняется: картинка не хуже (MAD к ПК-OpenGL и к предыдущему HW), воду не ломать. Цель: спрайты+HUD+небо+вода на EE ≤ 0.8 М на D1, ≤ 2 М на D4.
### STAB — продолжает (ждём его итог): полные прогоны на слитой сборке.
### CORE — в резерве: после слияния — проверка темпа 35 TPS/60 Гц на итоговой ELF.

## Железные правила раунда 2
* Каждая правка: A/B на одной ELF (флаг `-hwdbg`/`-hwgo`), числа по 4 демо; отклонения — в реестр; коммит и отчёт после каждого шага (лимит API может прервать сессию).
* Три агента правят общие файлы (`hw_main.c`, `hw_batching.c`, `ps2_hw_*.inc`): **часто вмешивай основную ветку** (`git merge claude/lucid-mayer-1izlqe`, она обновляется координатором), мелкие коммиты, не переформатировать чужое.
* Ничего не утверждать без запуска; честно писать, что цель не достигнута.
