# Оптимизация, агент S (кадр / система / GS / звук / логика): рабочий журнал

Сессия 2026-10-03. Каталоги вывода: `build/opt-s/` (сборки `*-build`, прогоны `<variant>`), эмулятор только через
`run_pcsx2.py` (общая блокировка). Единицы: такты COP0 EE на отрисованный кадр (1 кадр = 1 тик в `-timedemo`),
PCSX2 2.6.3 (профиль 32 МБ), **релизная сборка** (`-DNDEBUG`). Бюджет 8.43 М тактов/тик.

## Этап 1. Сборка: релиз по умолчанию, опции оптимизации

`tools/ps2/build.py`: (PS2-40) `-DNDEBUG` теперь по умолчанию; диагностическая сборка — `--debug` или `SRB2_PS2_RELEASE=0`.
`SRB2_PS2_OFLAGS` заменяет `-O2` везде (для замеров), `tools/ps2/opt_units.txt` / `SRB2_PS2_UNIT_FLAGS` — флаги отдельных единиц
(попадают в штамп флагов: смена -> полная пересборка).

Проверено по `-Q --help=target` и по ассемблеру (`build/opt-s/tmp`): `-march=r5900` задан компилятором по умолчанию, `-mtune`
совпадает (вывод `p_map.c` с `-mtune=r5900` побайтно тот же), код непозиционный (`jal` напрямую, `-G0`; `-mno-gpopt` лишний),
`-mfused-madd`/`-mbranch-likely` включены, `-msingle-float` (double — программный).

## Этап 2. Звук: что найдено

* `libvorbisfile` (`ov_read`) переводит каждый выходной сэмпл float -> int16 в **double** (`__extendsfdf2`, `__adddf3`,
  `floor`, `__fixdfsi` — найдено дизассемблером `libvorbisfile.a`): на EE без аппаратного double около 300 тактов на сэмпл.
* Замена: `ov_read_float` + `PS2_FloatToS16` (`src/ps2/ps2_pcmconv.h`) — результат побайтно тот же
  (`clamp(floor((double)(f*32768)+0.5))`), несколько операций одинарной точности.
* `PS2_MusicRender`: при 22 050 Гц и скорости 1 (шаг ровно 65536) — копирование блоками вместо цикла по кадру.
* `PS2_MixerRender`: курсор голоса в регистрах (раньше `v->frame/fraction` перечитывались после каждой записи из-за
  возможного алиасинга `int32_t`/`uint32_t`), специализация 8/16 бит x моно/стерео, деление на 256/32768 сдвигами с той же
  усечкой к нулю, быстрый путь `gain == 32768`.

Host-доказательство (MSVC): `python tools/ps2/audio_equiv_check.py` — 5 944 488 стереокадров микшера равны исходному
циклу побайтно **и** состояние голосов равно; 20 000 000 значений `PS2_FloatToS16` равны эталону через double; путь
копирования музыки равен данным файла (петля, нечётные блоки, EOF). Негативный контроль (`--negative-control`) краснеет.
`python tools/ps2/audio_check.py --host-only` (PCM/музыка/MIDI/backend) проходит.
