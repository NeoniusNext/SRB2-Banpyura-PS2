## 0. Старт (проверено запуском)

* Дерево собирается: `SRB2_PS2_OUT=build/opt8-s/out SRB2_PS2_RELEASE=1 python tools/ps2/build.py` — 117/117, ELF 9 725 832 Б (software). Вариант с аддонами (`SRB2_PS2_NO=lua,udmf,limits`) тоже собирается: 9 764 700 Б.
* Хост-тест HTTP-клиента PS2 (`ps2_curl.c`) против mock-мастера: `python tools/ps2/ps2_http_hosttest.py --out build/opt8-s/httptest` — режимы plain/chunked/redirect, **ALL PASS** (регистрация, update, unlist, список, 404, https отклоняется, отказ соединения, таймаут, плохой URL). Исправлено в самом тесте: относительный `--out` и экранирование `\ ` в bat.
* Реальный мастер-сервер SRB2 по обычному http отвечает (`curl http://ds.ms.srb2.org/MS/0/rooms` → 200, `/servers` → список): формат совпадает с mock, но **список содержит IPv6-адреса** (один хост перечислен дважды: v4 и v6) → PS2-131 (ниже).
* Инфраструктурный сбой: PCSX2 иногда не стартует (`Failed to create swap chain`, VK -13) — `net_session.py` теперь замечает выход эмулятора и возвращает 3 (`build/opt8-s/netrun.sh NAME` повторяет сессию до 4 раз); раньше сессия молча висела до таймаута (900 с под общей блокировкой).
