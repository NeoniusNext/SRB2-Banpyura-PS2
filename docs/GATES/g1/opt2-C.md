# Оптимизация 2, агент C (FPS: рендерер и кадровый цикл): рабочий журнал

Сессия 2026-10-04. Каталоги: `build/opt2-c/` (все сборки, прогоны, тесты). Эмулятор — только через `run_pcsx2.py` (общая блокировка).
Единицы: такты COP0 EE на отрисованный кадр (1 кадр = 1 тик в `-timedemo`), PCSX2 2.6.3 (32 МБ), релизная сборка (`SRB2_PS2_RELEASE=1`),
окна 1..9 по 105 кадров (945 кадров), окно 0 (загрузка уровня) отброшено. Бюджет 8.43 М тактов/тик. Эквивалентный FPS = 294.912 М / (такты/кадр), потолок 35.
