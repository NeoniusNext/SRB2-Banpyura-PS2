# OPT4, агент S (стабильность: память/загрузка + звук): рабочий журнал

Сессия 2026-10-05. Каталоги: `build/opt4-s/{out,outdbg,out-hw,out-os,run,sweep,zone}`. Эмулятор — только `run_pcsx2.py` через `opt_run.py`
(общая блокировка; очередь с агентами H и C — каждый прогон ждёт минуты). Релиз (`SRB2_PS2_RELEASE=1`), PCSX2 2.6.3, профиль 32 МБ.
Нумерация реестра: PS2-70..79. Строки PS2-60..63 (OPT3) в `docs/DEVIATIONS.md` не записаны — внесены координатору ниже (раздел 4).

## 0. Исходная точка (измерено на дереве старта OPT4, ELF 7 478 468 Б, 109 файлов)

* `base-m11` (`-warp MAP11 -zck -zquit 35`): **OOM** `PU_RENDERWORK 524288 Б`, кадр 2-3. Арена 24 887 296 Б (RAM 32 МБ - ELF/BSS 4.77 МБ -
  резерв libc 2 МБ - стек 512 КБ - ядро 1 МБ). Из них постоянно: уровень 18.0 МБ (PU_LEVEL 33 805 блоков), PU_STATIC 4.12 МБ, HUD-графика 0.46 МБ.
* Состав уровня MAP11 (25 100 линий, 49 592 сегмента, 4 828 секторов, 7 015 мобжей): lines 3.71 МБ (148 Б), mobj 2.92 МБ (416 Б),
  segs 2.38 МБ, sides 1.55 МБ, sectors 1.37 МБ (276 Б), nodes 0.83 МБ, blockmap 0.69+0.57 МБ, vertexes 0.47, things 0.37, ffloor 0.55 МБ (3 919 FOF).
* Рабочий набор кэша MAP11 при 128 МБ (ничто не вытесняется): текстуры 14.0 МБ + спрайты 3.4 МБ + флэты 1.5 МБ = 19 МБ.
  На 32 МБ остаётся 3.1 МБ (свободно после загрузки) => вытеснение идёт постоянно; каждый МБ свободного места — меньше перестроек.
* Загрузка MAP11 (EE-время `t_ms` по счётчику шины, `-zck`): старт движка -> начало загрузки уровня 10.2 с, сама загрузка 4.36 с
  (map-data 0.67, `P_SpawnSpecials` **2.30 с**, things 0.26).
* Стек главного потока: использовано 132 560 Б из 524 288 Б. Куча libc выше арены: пик 910 656 Б при резерве 2 МБ.
* `zone_hosttest.py` на дереве старта был красным (устаревшая проверка порядка вытеснения после PS2-63); исправлена тестом, не кодом.
