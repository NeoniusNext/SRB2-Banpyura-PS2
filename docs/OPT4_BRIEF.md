## Жалоба пользователя про HW (главный баг)
«В GS HW, когда появляется 3D-сцена, картинка застывает.» Это не `-timedemo`: нужно воспроизвести **обычный** запуск с `-renderer Hardware` (титул → меню → новая игра → GFZ1, и демо без `-timedemo`) в PCSX2 и найти зависание
(кадр перестаёт обновляться: вероятные причины — зависший DMA/VIF1/GIF (ждём `SIGNAL`/`FINISH`, не пришедший), переполнение кольца пакетов, неверный DMA tag/выравнивание, GS-контекст/FBP-перекрытие с экранным буфером, неснятый `I_Error` в `Impl_FinishUpdateHW`, смена видеорежима интерлейса).
Нужно: воспроизвести → причина → исправить → доказать прогоном (≥ 3000 кадров активной 3D-сцены без остановки счётчика кадров, лог в отчёт). Добавь в драйвер **watchdog** с диагностикой вместо тихого зависания.

## Роли (те же, нумерация продолжается)
* **H** — GS HW-рендерер. Приоритет: (1) устранить «застывание 3D-сцены», (2) визуальная корректность (без структурных артефактов), (3) скорость: цель — HW **быстрее** software и ≤ 4.9 М тактов EE/кадр. Допустимо радикально перепроектировать: VU1-микрокод, VIF1/GIF-цепочки, скретчпад, предвычисление статических данных карты (WORLD-геометрия в готовых GIF-пакетах/VU-буферах), перенос освещения в CLUT/alpha-проходы, политика текстур (прореживание/мип/ограничение, кэш по LRU). Нумерация `PS2-HW-21..` (в DEVIATIONS уже есть PS2-HW-15..20 в отчёте — проверь, чтобы не пересечься). Отчёт `docs/GATES/g1/opt4-H.md`. Каталог `build/opt4-h/{out,run}`.
* **C** — software + кадровый цикл + общее CPU-ядро (P_Ticker, thinkers, blockmap, HUD). Цель: максимально снизить такты (хост-тест/golden 0 px различий, негативный контроль), 60 FPS показа через интерполяцию при 35 TPS там, где позволяют такты. Нумерация `PS2-90..99`. Отчёт `docs/GATES/g1/opt4-C.md`. Каталог `build/opt4-c/{out,run}`.
* **S** — стабильность: память (MAP11 и все карты кампании на 32 МБ: `map_sweep.py`), загрузки, звук без глюков, утечки при смене карт ×50, **память HW-режима** (согласуй бюджет с H). Нумерация `PS2-70..79`. Отчёт `docs/GATES/g1/opt4-S.md`. Каталог `build/opt4-s/{out,run}`.
