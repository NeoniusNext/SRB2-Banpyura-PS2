## Why the previous rejection needs a controlled test

The ninth-pass pressure observations are retained with their original values
in [the historical I/O report](PS2_IO_NEXT9_20261115.md). Their causal
interpretation is superseded. `-singletics` fixes `P_Random`, while the local
`M_Random` generator still takes its seed from OS clocks. Ambient thunder
selects `DSATHUN1`/`DSATHUN2`, whose decoded sound-cache payloads differ by
350 B (331,330/331,680 B). Those allocations can independently change cache
topology and resource reconstruction.

The old one-unit opt-out controls the other IR inputs; it does not control
that game workload. Its observed restoration of cache metrics and elapsed
time therefore does not establish that the overlay caused the difference.
The historical rollback remains a fact. Neither rejection nor adoption can
be justified by treating those unseeded traces as controlled comparisons.

The eleventh-pass adoption plan requires the coordinator's diagnostic ELF
copies with both preselected local seeds, `0x01b2d3f5` and `0x9e3779b9`,
preserving each original ELF's address layout and using identical 32 MiB MAP11
`-keepspawn` 350-frame inputs. The primary seed already fails the gate, so
there is no adoption and no secondary candidate run. The new current-baseline
controlled rejection below is separate evidence. It does not retroactively
make the ninth-pass workload controlled. Published game RNG initialization
remains unchanged.

## Representation and exact lifetime

Each of the six streams overlays its 128-byte raw signature/header probe
with the 64-byte parsed header and 64-byte parsed extension. Existing `hdrok`
selects these mutually exclusive lifetimes. No slot, path capacity, header
field, extension field, reserved word, offset, pointer, size or device policy
is reduced. There is no persistent scratch or new heap allocation.

`ReadHeader` is byte for byte unchanged. It keeps its private outputs and
validation/error order. Only the existing final successful assignments
publish both complete parsed structures and set `hdrok`; every failed parse
retains all raw cache bytes. Its error callbacks can reenter parsing.

After slot turnover, `WPack_VerifyNMUS` or `WPack_GetLumps` can parse a stream
before its first signature probe, leaving `hdrok == true` and `magic == 0`.
A subsequent detection must inspect the current source without overwriting
the cached parsed view. `PeekCheckedMagic` supplies a private 128-byte stack
probe for this edge. Zeroing, read size/order, short-circuit signature test,
magic update and descriptor reset match the preceding probe. Real changed,
truncated or non-pack sources retain the preceding detection/drop behavior;
a still-valid signature retains the preceding parsed cache behavior.

Lazy stream/index/LZ4 allocation, read windows, prefetch, the shared aligned
bounce/decoded buffer, retries, errors and recovery-readiness policies remain.
No stronger purge, reduced budget, different resource limit or quality change
is proposed.

## Reproduction

Use fresh output directories. The host commands do not invoke EE compilation
or emulation:

```sh
python3 -B tools/ps2/next11_io_prepare.py
python3 -B tools/ps2/next11_io_hosttest.py --negative-controls --corpus
python3 -B tools/ps2/next11_io_retention.py
```

After the global EE worker grant, build each isolated one-unit control using
`next11_io_lto.py --canonical build/nov15-next11/baseline/{software,hardware}
--out <fresh-dir> --link`; add `--optout` for restoration. Run
`next11_io_objectcheck.py` with the complete frozen Software canonical build.
For each object/ELF pair, run `next11_io_codecheck.py` with baseline/current
engine and ELF paths, `--isolated` and a fresh `--out` report; add `--optout`
for the complete restoration gate. No proof tool edits production source.
Run `next11_io_negative.py` for the executed binding mutations. After the
coordinator's controlled emulator run, use `next11_io_pressure_audit.py
--pressure <completed-pressure-dir> --out <fresh-audit.json>` for the read-only
whole-ELF, sound, runtime-input and 13-field decision binding.
