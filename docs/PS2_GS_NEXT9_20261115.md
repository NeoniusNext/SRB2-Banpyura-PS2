# Exact GS state-address staging, ninth pass, 2026-11-15

`state_flush` now stages its GS register addresses in `u8 regs[10]` instead of
`u32 regs[10]`. This is the only production GS change. Every staged address is
a literal in `0x01..0x4e`; all ten conditional writes together fit the original
ten slots. Unsigned byte loads preserve the original zero-extended A+D address.
The parallel 64-bit register values remain unchanged.

The actual default full-LTO Hardware helper shrinks **1360 to 1320 bytes**, and
its stack frame shrinks **160 to 128 bytes**. The address-array index no longer
requires a multiply by four. This saves 40 bytes of this helper's loaded code
and 32 bytes of stack while the helper is active. It does not shrink the
pre-reserved main stack, persistent state, ring buffers, heap or VRAM.

The source reference is frozen revision
`19cf5df2a82b04e37fabe76a4441f3d5062ebaf1`, reconstructed in
`build/nov15-next9/baseline-src/src`. Replacing this one temporary type restores
the entire frozen `ps2_hw_draw.inc` byte for byte. The driver, private layout,
register helpers, DMA/VIF/VU transport, texture kernels and model source are
separately checked for byte identity. State-cache updates, conditional tests,
CLD reload rules, packet reservations, register order and packet bytes retain
their original order and values. No formats, alpha, keys, palettes, dimensions,
filtering, geometry, precision, capacity or resource lifetimes change.

## Independent packet and state proof

The ordinary host and ASan/UBSan runs each pass **1,070,080 cases and 6,410,547
register writes**. The fixture extracts the actual frozen/current state helper
and the unchanged production `ad_alloc`, `pk_alloc` and `ad_set` into separate
translation units. An independent oracle uses its own ordered field/address
table and its own TEX0/CLD comparison to construct complete expected A+D
packets and private-state results. It compares every emitted packet byte,
immediate pre/post canaries, exterior ring canaries, all 36,896 private-state
bytes and the unchanged input state.

Every pair of ten-bit validity and dirty masks occurs, with balanced optional
texture/fog use. Additional cases cover all eight CLD values, all four optional
use combinations, noncanonical truthy flags, 64-bit register values, high
validity bits, wrapping serial/write counters, all four ring buffers, every
available-space position around the largest packet, pending VU predicates and
repeated changed inputs. Capture-only completion hooks record the state seen
at the ownership boundary, model a ring rotation and exercise subsequent
state invalidation. They do not replace production allocation logic.

All six executed mutations fail: wrong register address, changed value bit,
missing forced CLD reload, skipped fog write, changed validity mask and missing
last register write. Failure returns remain visible in their raw logs.

The native proof uses **37,888 cases and 229,516 register writes**, including
all validity masks, four dirty-mask families with each optional-use combination,
the complete boundary/CLD/VU matrix and random cases. The same shorter corpus
also runs on the host and produces identical case/write totals. All random
draws are explicitly sequenced across architectures.

An initial fixture left the order of random function arguments unspecified.
Both oracles passed, but the strict report rejected its different host/EE
write totals. That fixture, its exact original source hash, first run and
rejection reason remain in
`build/nov15-next9/gs/initial-unsequenced-fixture`. The final fixture fixes
that test determinism issue; production code is unchanged by that correction.

## Actual engine instructions and timing scope

The timing fixture embeds each **complete original function section and all
eight ordered RELAs** from the saved baseline and candidate default full-LTO
Hardware `engine_lto.o`. The assembler output must match every original section
byte and relocation. A separate checker applies those relocations and checks
every resolved function byte against both the real Hardware ELF and fixture
ELF. Instruction-bit, moved-relocation and changed-explicit-addend mutations
are rejected. The fixture retains the real `H`, `V` and `VU` symbol sizes and
the actual offsets used by the embedded code, with whole-state canaries.

`ad_alloc` and the ordinary `pk_alloc` reservation path are already inlined in
this real game helper; those instructions are included in the measured body.
Its out-of-line VU-completion and ring-flush calls target capture-only hooks
in the fixture. Timed rows keep enough ring room and no pending VU chunk, so
those hooks are not called inside measurement windows. The separate exactness
matrix exercises those boundaries. These are complete state-helper timings,
not the full production DMA/VU call closure or device waits.

Nine repetitions alternate baseline/current order through volatile function
pointers. Interrupts are masked only inside each timer window, and their prior
enabled state is restored afterward. Each last timed packet, its surrounding
canaries and the whole final state are checked against the independent oracle
for the exact timed parameters, then compared between versions. The report
requires all 64 prescribed configurations and all nine repetitions.

The 64 configurations include no-change calls, one changed register at every
position, alternating/dense changes, invalid cache state, optional texture/fog
state and forced CLD reload. Each row measures 2048 complete calls with equal
state reset, call and result-observation overhead. The measured change is
local CPU work; no game-frequency-weighted FPS, physical-console speedup,
reduced GIF/DMA traffic or reduced GS raster work is claimed.

**46 configurations improve, 18 are exact ties and none regress.** The summed
median cost is **30,895,040 to 30,661,568 cycles, a 0.7556941% reduction**.
All no-change calls tie. These sums include equal fixture reset/call/observation
overhead; they are not weighted by the game's state-change frequency.

## Reproduction

Use the configured SDK and standard 32 MiB emulator profile from
[TOOLCHAIN.md](TOOLCHAIN.md). Supply actual full-feature default-LTO Hardware
objects and ELFs; a replacement separate-TU C build is not timed.

```sh
python3 -B tools/ps2/next9_gs_hosttest.py \
  --out build/next9-gs-host --base-src build/nov15-next9/baseline-src/src \
  --sanitize --negative-controls
source /workspace/.onboarding/environment.sh
python3 -B tools/ps2/next9_gs_hosttest.py \
  --out build/next9-gs-ee --base-src build/nov15-next9/baseline-src/src \
  --ee-only \
  --baseline-engine build/nov15-next9/baseline/hardware/engine_lto.o \
  --current-engine build/nov15-next9/gs/candidate-hardware/obj/engine_lto.o
source /workspace/.onboarding/emulator-env.sh
python3 -B tools/ps2/run_pcsx2.py \
  --elf build/next9-gs-ee/GS_NEXT9.ELF --log build/next9-gs-ee/run.log \
  --until 'GS NEXT9 DONE' --timeout 240
python3 -B tools/ps2/next9_gs_hosttest.py \
  --out build/next9-gs-ee --summarize build/next9-gs-ee/run.log
python3 -B tools/ps2/next9_gs_hosttest.py \
  --out build/next9-gs-ee \
  --baseline-engine build/nov15-next9/baseline/hardware/engine_lto.o \
  --current-engine build/nov15-next9/gs/candidate-hardware/obj/engine_lto.o \
  --baseline-elf build/nov15-next9/baseline/hardware/SRB2.ELF \
  --current-elf build/nov15-next9/gs/candidate-hardware/SRB2.ELF \
  --fixture-elf build/next9-gs-ee/GS_NEXT9.ELF --negative-controls
python3 -B tools/ps2/next9_gs_finalbind.py \
  --out build/next9-gs-final-binding \
  --baseline-engine build/nov15-next9/baseline/hardware/engine_lto.o \
  --measured-engine build/nov15-next9/gs/candidate-hardware/obj/engine_lto.o \
  --current-engine build/nov15-next9/hardware/obj/engine_lto.o \
  --baseline-elf build/nov15-next9/baseline/hardware/SRB2.ELF \
  --current-elf build/nov15-next9/hardware/SRB2.ELF \
  --fixture-elf build/next9-gs-ee/GS_NEXT9.ELF \
  --build-report build/nov15-next9/hardware/build-report.json
```

Raw source audits, generated C/assembly, all build logs, packets/state results,
negative controls, complete code/RELA binding and timings are under
`build/nov15-next9/gs/{host,ee}`. The component fixture compiles without
diagnostics under `-Werror`; the link retains the existing SDK ABI warning.
The shipping default game build reports zero compile/link diagnostics.
The earlier stable copied timing-source build also includes the rejected I/O candidate,
so no whole-build text,
BSS or ELF-size difference is attributed to this GS change. The timed helper
binds to the shipping Hardware image; every later rebuilt image needs a new
binding with its actual object, ELF and build report.
