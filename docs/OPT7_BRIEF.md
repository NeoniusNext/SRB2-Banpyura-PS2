## Требования пользователя (повтор, это критерий приёмки)
1. Намного больше FPS на PS2 (цель ≈ 60 FPS при 35 TPS), намного выше стабильность. Рендер/движок можно переписывать, графику/физику сохранять (допуск — малая погрешность).
2. **Главное: полностью завершить GS Hardware Renderer** — нативный PS2 (GS + VU0/VU1 + DMA + scratchpad), все эффекты/освещение/возможности OpenGL-HW рендерера SRB2 (в пределах возможностей GS), стабильный, **без графических багов («текстуры на стенах и полах глючат»)**, FPS заметно выше software. Можно переписывать HW-рендерер, «шейдеры» и функции под PS2.
3. Вернуть всё, что вырезал `PS2_PROFILE`: **аддоны (pk3/wad/soc/lua, меню Add-ons), Lua, UDMF, multiplayer (сплитскрин и сеть, подключение к серверам), мастер-сервер (список серверов + регистрация хоста)**. Ванильный режим остаётся лёгким и golden-эквивалентным.
4. В конце — единая ELF со всем: аддоны, Lua, UDMF, сеть, мастер-сервер; плюс вариант с `-renderer Hardware`.

## Роли (владение файлами как в OPT6; чужое — отчётом координатору)
### H — GS Hardware Renderer (главный приоритет, `PS2-HW-22..`)
1. Дефект «текстуры на стенах/полах глючат»: снимки `-renderer Hardware -vidshot` на разных картах (GFZ1/2, THZ1, DSZ, CEZ, ACZ, спец-этап, титул), побайтный/визуальный диф со software, найти **измерением** причины (Q/ST и перспектива, округление UV/XYZ, wrap/repeat NPOT и tiling, CLUT/AP88, мипы/фильтр, вытеснение пула VRAM, z-fighting, near-clip, сортировка/декали, FOF, наклонные плоскости). Исправить, доказать до/после и хост-тестом.
2. Паритет эффектов с OpenGL HW (свет секторов/colormap/fog/fade, прозрачности и аддитив/вычитание, небо, вода/FOF, наклонные плоскости, спрайты, модели, palette flash, wipe, HUD/меню, Lua-HUD). Невозможное на GS — заменить и записать (`PS2-HW-*`, погрешность).
3. Скорость: HW явно быстрее software (цель ≤ 4.9 М тактов EE/кадр). VU1-микрокод/VIF1 DMA, батчинг, кэш текстур VRAM, предвычисленная геометрия карты. Замеры только релиз, одинаковые демо.
4. Интерполяция кадров для показа 60 Гц (35 TPS не трогать); стабильность (смена рендерера, меню, 50 смен карт, ≥ 3000 кадров, watchdog = 0).
5. Рекомендация координатору: HW рендерером по умолчанию или нет (с числами). Подготовка HW к сплитскрину (viewport/scissor) — согласовать с S.
### F — Возврат контента (`PS2-100..119`) — продолжай с этапа (b)
(b) настоящая Lua-VM вместо `lua_stub.c` + `LUA_EvalMath` (таблица `soc_numbers` остаётся быстрым путём), (c) UDMF, (d) аддоны (`addfile`, меню Add-ons, `host:`/`mc0:`/`mass:`, автозагрузка, скины/спрайты/звуки/музыка/SOC/Lua из аддонов, сейвы/демо с аддонами),
(e) лимиты (freeslots, `skin_t` динамически, `MAXFRAMENUM`, SFX-слоты, custom gametypes). Каждый этап = тест (`make_addons.py`/`ftest_run.py`/`ftest_check.py`, при возможности сравнение с ПК-сборкой), 4 golden-демо 0 px, память ванильного режима не растёт. Lua+HW/software одинаково (HUD drawlist, хуки).
Когда этап готов — убрать его из `SRB2_PS2_NO` по умолчанию в `build.py` (точечная правка). Итог: все пять этапов включены в обычной сборке.
### S — Память/стабильность + сплитскрин + сеть + мастер-сервер (`PS2-70..79`, `PS2-120..139`)
1. (≤ 1/3 усилий) MAP11 OOM, `map_sweep.py` по всем картам, утечки ×50 смен карт; бюджет памяти (таблица) для F и H.
2. Сплитскрин 2–4 игрока (software и HW), pad'ы/multitap, меню.
3. Реальная сеть: lwIP/ps2ip BSD-sockets вместо `net_stub.c`, UDP как `i_tcp.c`, хост/клиент, передача файлов аддонов (`d_netfil`), доказательство N тиков без десинхронизации (PS2-сервер ↔ ПК-клиент из репо и/или две копии PCSX2, DEV9 Sockets/TAP).
4. **Мастер-сервер**: список серверов (меню «Join»/«Server browser») и регистрация хоста (`mserv.c`/`http-mserv.c`: на PS2 нет libcurl → минимальный HTTP/1.1-клиент поверх сокетов, при необходимости DNS и TLS-заглушка/HTTP-порт; адрес мастер-сервера настраиваемый `masterserver`). Доказательство: локальный mock-мастер-сервер (Python) принимает регистрацию PS2-хоста и отдаёт список PS2-клиенту.
Если какой-то пункт упирается в ограничение PCSX2/железа — записать факт и сделать максимум возможного (код + хост-тест), не имитировать успех.
