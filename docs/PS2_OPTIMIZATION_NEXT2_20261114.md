## Полные сборки и память

Обе release-сборки используют обычные настройки порта, LTO и все стандартные
возможности. Варианты с отключёнными функциями не являются итоговыми.

| Секции ELF | Предыдущий проход | Второй проход | Разница |
| --- | ---: | ---: | ---: |
| Software: text + data + BSS | 6682801 Б | 6683217 Б | +416 Б |
| Hardware: text + data + BSS | 7921348 Б | 7885724 Б | −35624 Б |
| Hardware: BSS | 2236868 Б | 2199940 Б | −36928 Б |

Hardware text вырос на 1304 Б; data не изменилась. Поэтому экономия BSS
отдельно не выдаётся за экономию всего загружаемого образа.

На стандартном 32 МиБ профиле PCSX2 MAP01 прошёл 175 кадров с проверкой
блоков и владельцев каждый кадр (`-zheap 1`), проверкой памяти и стека:

| Снимок после 175 кадров | До | После |
| --- | ---: | ---: |
| Hardware: свободная арена | 5252576 Б | 5291120 Б |
| Hardware: свободная libc-куча | 181992 Б | 180776 Б |
| Hardware: сумма свободного | 5434568 Б | 5471896 Б |
| Software, Lua HUD и MIDI: свободная арена | 8175968 Б | 8179376 Б |
| Software, Lua HUD и MIDI: свободная libc-куча | 577048 Б | 580824 Б |

Итого в этих сценариях свободной RAM стало больше на **37328 Б в Hardware**
и **7184 Б в Software с Lua HUD/MIDI**. Это фактические снимки конкретных
сцен, а не сумма всех корпусных экономий. Песня `D_GFZ1` имеет 18 дорожек;
её отдельный MIDI-блок уменьшается с 12016 до 7864 Б. Максимальный стек
игровой нити остался 132560 Б из 384 КиБ; у декодера в MIDI-сцене замерено
1296 Б из 32768 Б. OOM, ошибок владельцев и underrun в этих прогонах нет.

Проверочный Software-сценарий с Lua HUD/MIDI дал 1752310388 → 1683363084
отсчётов COP0 (−3,93%) и 9173 → 8911 мс. Hardware с проверкой кучи каждый
кадр: 1095401092 → 1098766179 отсчётов (+0,31%) и 13947 → 14286 мс.
Эти короткие прогоны содержат ожидания, загрузку и диагностический обход;
по ним не заявляется универсальный прирост FPS. На физической PS2 FPS,
работа её кешей и слышимый звук в этой сессии не измерялись.

## Графика, состояние и совместимость

При одинаковом seed и `-singletics` совпали **10/10 полных PPM 320×200**:
MAP01 Software/Hardware по три кадра, Lua HUD с четырьмя вариантами обрезки,
отображения цветов и прозрачности при MIDI — ещё по два кадра в каждом
рендерере. Ни пиксели, ни области не исключались из сравнения.
`tools/ps2/next2_ui_fixture.lua` — только тестовый аддон, в итоговую игру он
автоматически не загружается. `-nodigmusic` в этом тесте выбирает штатный MIDI;
цифровая музыка остаётся включена в обычной сборке.

Дополнительно обновлённый standalone GS-тест CT32 даёт прежние **55/56**:
единственный сбой — известные 24625/49152 расхождений outcode `vu0_transform`,
при тех же X/Y/Z/Q. Все 17 полных снимков GS совпали с предыдущим проходом.
CT16S с двумя добавленными проверками текстурированных моделей даёт **50/51**,
с тем же единственным расхождением VU0.
Проверки палитр, alpha, фильтрации, моделей, перспективы, снимков экрана,
вытеснения текстур и нехватки VRAM прошли; пропавших текстур и таймаутов нет.
Набор с этим старым сбоем не объявляется полностью зелёным.

Подробные тесты с реальными исходниками, ASan/UBSan, состоянием и намеренными
ошибками:

## Артефакты и воспроизведение

```text
Software: build/ps2/SRB2.ELF
SHA256: 30fef9b92c863a3a03a135a8198217232ea48ff6463cfd7ef22a2c5ee26851fc
Hardware: build/nov14-next/hardware/SRB2.ELF
SHA256: 4400bb10b7060679233788ec94fc4e28c8ff7cfec79f345ea9561a94d0b3c310
```

Предыдущий проход не был коммитом. Для воспроизводимого сравнения добавлены
`next2_baseline.patch/.json` и `prepare_next2_baseline.py`: они экспортируют
известную базовую Git-ревизию, применяют замороженные изменения только внутри
`build` и проверяют SHA256. Полное восстановленное дерево `src` также было
сверено побайтово с исходным снимком. Рабочие исходники и Git index не меняются.

```sh
source /workspace/.onboarding/environment.sh
source /workspace/.onboarding/emulator-env.sh
python3 -B tools/ps2/prepare_next2_baseline.py
python3 -B tools/ps2/build.py --jobs 2
SRB2_PS2_HW=1 SRB2_PS2_OUT=build/nov14-next/hardware python3 -B tools/ps2/build.py --jobs 2
```

Логи игровых прогонов: `build/nov14-next/runs`; сводка, хеши исходников и
сверки кадров: `build/nov14-next/integration-report.json`.

Устранение временной таблицы колонок текстур не включено: проверка настоящего
аллокатора обнаружила увеличение пика при последующем перемещении блока.
Выравнивание пикселей также сохранено, чтобы не переводить существующие
MMI-копирования на медленный путь. Кандидаты предыдущего прохода с повышенным
пиком аддонов или риском восстановления после OOM остаются исключены.
