Работа велась агентами CORE, GEOM/GEOM2, FX/FX2/FX3, VU/VU2, STAB, MODEL, AUDIO, NETUI в отдельных worktree; ветки слиты в `claude/lucid-mayer-1izlqe`.
Подробности и реестры — `docs/GATES/g1/opt11-*.md`, `docs/OPT11_BRIEF.md`, `docs/OPT11_ROUND2.md`, `docs/OPT11_MODEL_BRIEF.md`.
Эмулятор: PCSX2 2.6.3 (программный GS), 32 МБ; **настоящая консоль не проверялась**.

## ВАЖНО: итоговый ELF `prebuilt/SRB2-PS2-OPT11-final.ELF` — сдан БЕЗ тестов
По требованию пользователя («без тестов, сразу») финальное слияние (GEOM2 + FX3 + STAB (раунд 2) + NETUI + MODEL showmem) только **собрано** (PS2 full+HW с LTO и ПК), на эмуляторе
не запускалось и golden на нём не проверялся. Проверки каждого агента делались на его собственной базе. Предыдущий проверенный ELF — `prebuilt/SRB2-PS2-OPT11-r1.ELF`
(CORE+GEOM+FX+VU+снимок STAB: golden software 0 differ, DEMO_001 в обоих рендерерах, DEMO_003 в HW до конца, MAP11 откат на software).
Слияние STAB, GEOM2, NETUI имело конфликты (`ps2_hw_vu1.inc`, `ps2_hwd.c`, `hw_batching.c`, `i_video.c`), разрешённые сохранением обеих сторон и одной правкой аргумента `vu_dump`.

## Что сделано
* **VU1-конвейер по умолчанию (VU, VU2):** трансформ, отсечение, палитровый свет с резкой по рядам colormap на VU1, упаковка GIF, сбор полигонов блоками на лету, резка по повторам на VU1.
* **Вода (FX):** причина глюка — шейдер ПК считает фазу ряби в секундах, драйвер — в тиках; исправлено, швы между полосами убраны, дальняя рябь без обрыва. Исправлены пропадающая тень, свет моделей, устаревшие CLUT освещения.
* **Звук (AUDIO):** причина глюка SFX без музыки — поток IOP безусловно двигает позицию чтения кольца 9400 Б, при отставании EE хвост кольца повторялся (до 11 с); исправлено (PS2-300/301), underruns 0. Стоимость аудио −65 % (VU0/MMI, быстрый Huffman), PCM побитно прежний (скалярный путь), VU0-путь ±1 LSB у 0.06 % отсчётов (на железе не проверено).
* **Стабильность (STAB):** восстановимая нехватка памяти с откатом HW↔software вместо `I_Error` (MAP11 в HW сам идёт на software), DEMO_003 в HW доходит до конца, корень зависания GS на MAPMD/MAPME (хвост загрузки текстуры, PS2-HW-144), MAPMG в software открывается, 84 карты в HW цепочкой, 29 сетевых сценариев без расхождений (на сборке m9–m11).
* **Модели (MODEL):** MD3 на GS (`gr_models`, по умолчанию Off как на ПК): `MODELS.PAK`, ленивое чтение кусками, свет моделей, цвет скина, `gr_modeldetail`; показ RAM/VRAM `showmem` (по умолчанию Off).
* **Интерфейс (NETUI):** экран подъёма сети (DHCP) рисуется и в Hardware, в стиле меню; набор иконок кнопок PS (7 px для строк), подсказки меню (`menuhints`, по умолчанию Off), без дубликатов.
* **Логика тика (CORE):** быстрые пути, заголовок зоны 2 МиБ; software DEMO_003 14.2 → 11.7, DEMO_004 13.8 → 12.3, физика и кадры побитно (golden 0 differ).

## Не закрыто / не проверено (честно)
* Цели по FPS (60 FPS; HW намного быстрее software); 2 из 6 «целей раунда 2» по стадиям не достигнуты (фронт ≥ 2.1 М, тыл ≥ 2.2 М против 1.3 М).
* Финальное слияние не запускалось (см. выше). NETUI: сеть PS2-клиент HW ↔ ПК-сервер в последней сессии дала таймаут (причина не выяснена); экраны сети/подключения на последней сборке и обход меню в HW не проверены; `menuhints` выключены до проверки.
* STAB: интерпретатор + EnableEECache на слитой сборке, soak 20 мин, files/packs/leak и `server-kill-hard` не прогонялись; MAP11 в software проходит почти без запаса (0.3–0.5 МБ).
* MODEL: `gr_models Off` — 0 пикселей не подтверждён строго (различия в десятки–сотни пикселей из-за чувствительности планировщика текстур к раскладке памяти/тактам); сеть с моделями не проверена.
* GEOM2: кэш блоков VU1 (PS2-HW-215) выигрыша не дал (откачен); кэш плоскостей выключен.
* Реальное железо: кэш данных EE, DMA, VU1, звук, GS — только модель PCSX2.
