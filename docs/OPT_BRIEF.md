# Бриф оптимизации (сессия 2026-10-03): software-рендерер, CPU/RAM/VRAM, 32 МБ

Проект: нативный порт SRB2 2.2.15 на PS2 (EE R5900 294.912 МГц, GS 4 МБ VRAM, **32 МБ ОЗУ**), запуск только в PCSX2.
Рабочая копия `D:\Ai-Project3\SRB2-PS2-Port`, ветка `ps2`. Общее рабочее дерево: **три агента одновременно**.
Обязательно прочитать: `docs/AGENT_BRIEF.md` (железные правила: ничего не утверждать без запуска, не менять игровую логику/демо/сейвы,
правки ядра только под `PS2_PROFILE`/`PS2`, не коммитить, свой `SRB2_PS2_OUT`/`SRB2_PS2_RUN`), `docs/PS2_MEMORY.md`, `docs/DEVIATIONS.md`
(формат строк), `docs/PLAN.md` §6-§7.

## Цель пользователя
1. Максимально ускорить software-рендерер и весь кадр (FPS намного выше). Бюджет — **8.43 М тактов EE на тик (35 Гц)**.
2. Максимально снизить расход ОЗУ, VRAM, CPU, GPU.
3. Игра должна **стабильно работать на 32 МБ без вылетов**, большие карты должны надёжно загружаться.
4. **Без потери** качества графики, возможностей, физики. Допускается *очень малая* погрешность (единицы пикселей на кадр, не накапливающаяся
   в физике). Игровая логика/RNG/демо/сейвы — побайтно как в оригинале (демо `golden/phase0-v2` = эталон).

## Базовые цифры (измерено 2026-10-03, PCSX2 2.6.3, ZDEBUG-сборка без `SRB2_PS2_RELEASE=1`, DEMO_001, циклы COP0 на кадр)
Окно 105 кадров: total 3.4-4.1 G => **16.5-39 М тактов/кадр** (бюджет 8.43 М). Доли: BSP/стены 38 %, planes 29 %, audio 8 %,
P_Ticker 4 %, masked 6 %, render-setup 6 %. Ориентиры: `build/opt-session/base/perf.json`, `boot-DEMO_001.txt`.
**Всегда замеряй релизную сборку:** `SRB2_PS2_RELEASE=1` (иначе включены ZDEBUG/RANGECHECK/PARANOIA — искажают цифры).

## Инструменты (уже есть)
* Сборка: `SRB2_PS2_OUT=<свой каталог> SRB2_PS2_RELEASE=1 python tools/ps2/build.py [--ps2ref] [--syntax файлы]`.
* Профиль фаз: `SRB2_PS2_RUN=<свой каталог> python tools/ps2/perf_phases.py --variant NAME --out build/<свой> --scenarios DEMO_001,DEMO_002`
  (нужно `SRB2_PS2_RELEASE=1` в окружении); сценарии/параметры — в docstring. Эмулятор — только через обёртки (общая блокировка, ждать очереди нормально).
* Прогон карты/демо с памятью: `tools/ps2/opt_run.py` (`--ram 32|128`, `--map MAPxx`, `--demo`), `-zquit`, `-memtrace`, ZSTAT/PROF строки.
* Эквивалентность: golden-сравнение демо `tools/ps2/run_ps2_ref.py --mode demo --demo DEMO_00n` (тики, индексные кадры 0 px различий)
  и хост-тесты `tools/ps2/*_hosttest.py` (`--negative-controls`). Любая оптимизация = хост-тест эквивалентности + замер COP0 до/после.
* PCSX2 не моделирует кэш EE: цифры — оценка стоимости инструкций; учитывай реальный D-cache (8 КБ), scratchpad 16 КБ, `pref`.
