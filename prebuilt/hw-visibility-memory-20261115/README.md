# PS2 Hardware: память и frustum test

`SRB2-PS2-Hardware.ELF` — полная обычная Hardware/LTO-сборка с прежними
функциями, настройками качества, форматами и разрешением.

- Запись текстуры EE: **148 → 140 байт**, −4096 байт на первые 512 записей.
- В свежем сопоставленном 350-кадровом MAP02-прогоне `used/peak/gpeak` и spill
  ниже на **4096 байт**. Размер арены, C-куча, стек, вытеснения и resource traces
  сохранились; свободное место арены увеличилось на 4096 байт.
- Прежний frustum test быстрее на **10,3–25,6%** в 18 отдельных EE/PCSX2
  тестах. Это не измерение общего FPS или физической PS2.
- Все **15 полных игровых PPM-пар и 17 GS-снимков** побайтно совпали с базой.

Нового снижения занятой VRAM в этой волне нет. Сохраняется строгий численный
VU0 FAIL: CT32 55/56, CT16S 50/51, оба exit 1. Флаги отсечения теперь совпадают;
`dZ=86` и `q_rel=3.61343e-05` превышают прежние допуски. Арифметика transform
и допуски не изменены; ошибочная подготовка диагностического hook исправлена.

База — `e10593b0d`. Метаданные сборки закреплены на ней для сопоставления;
действительный исходник из коммита `6882119d4` определяет
[`source-sha256.json`](source-sha256.json), проверенный для всех 602 файлов.
`_end` и `_gp` совпадают с базой. Полная карта статических адресов не объявляется
неизменной: малые `.sdata` объекты переместились после удаления diagnostic literals.

[`validation.json`](validation.json) содержит реальные результаты, сохранённый
неуспешный GS status, контрольные суммы и ограничения.
[Отчёт](../../docs/PS2_HARDWARE_VISIBILITY_MEMORY_20261115.md) описывает исходники,
отклонённые варианты и воспроизведение; [архитектурные источники](../../docs/research/opt15/PS2_ARCHITECTURE_SOURCES.md)
содержат проверенные SCE/PS2SDK/gsKit ссылки. BIOS и игровые ресурсы не включены.
