SRB2-PS2-OPT14.ELF: ветка claude/srb2-ps2-optimization-gk1x6k, слияние OPT12 (HWFRONT, HWDRV, NET, LOAD, CORE) + OPT13 (IO, IQ, IZ, IR, IS) + OPT14 (CHAT, GIF, LUA), коммит 329fefb и этот файл.
Релиз, LTO, Software + Hardware: SRB2_PS2_NO= SRB2_PS2_HW=1 python3 tools/ps2/build.py --jobs 2.
Паки (SRP2 v2 + MODELS.PAK + TEXC.PAK): cook.py --src <папка pk3 SRB2 2.2.15> --out <каталог>; gen_fineacon.py; cook_models.py; cook_texc.sh <каталог> <каталог>. Готовая раскладка: make_dist.py --elf prebuilt/SRB2-PS2-OPT14.ELF --pak <каталог> --out dist/SRB2-PS2 --zip.
Режим вывода по умолчанию по региону консоли (европейская = PAL 50 Гц); для 60 Гц нужен NTSC (-ntsc или меню видеорежимов).
Новое в этой сборке: пункты Chat / Team Chat в меню паузы сетевой игры (экранная клавиатура внизу, Select = Talk, R2 = Talk Team); запись GIF больше не включается при подключении к серверам; исправления Lua (userdata корутин, O(n^2), порядок аргументов, куча); сеть PS2<->ПК (пинг ~30 мс, нет зависания подключения в Hardware); быстрее загрузка (старт, карты, аддоны, UDMF); паки читаются окнами по носителю; детерминированная зона; хранимые записи геометрии, слитый путь спрайтов.
Проверено в PCSX2 2.8.2 (32 МБ, программный GS), НЕ на настоящей консоли: Software кадры побитно = golden/ps2-head, физика = ПК (4 демо); таймдемо реальных тиков на 1051 игровой: Hardware D1..D4 817/864/1174/1036, Software 1001/1040/1383/1459.
Известное: цель 60 FPS не достигнута (Hardware 31..45 FPS в эмуляторе, на консоли по модели ещё в 1.65-2.0 раза медленнее); открыто: Lua valid==false у части line/subsector на втором уровне сессии и падение декодера музыки при частой смене уровней (агент FIX, не слито в эту сборку).
