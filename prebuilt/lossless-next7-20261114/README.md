# SRB2 PS2 — седьмой проход, 2026-11-14

Проверенные release-сборки из исходников
[`2ec90684a`](https://github.com/NeoniusNext/SRB2-Banpyura-PS2/commit/2ec90684af655a9286b097224564083c4a007170):

- [Software](SRB2-PS2-Software.ELF).
- [Hardware + Software](SRB2-PS2-Hardware.ELF).
- [SHA256SUMS](SHA256SUMS) и [результаты проверок](validation.json).

Каталог стандартных паков занимает на 60 208 байт меньше RAM. Блок открытой
WAV/MIDI/MP3-музыки уменьшен на 720 байт; для Ogg размер сохранён. Ускорены
семь функций тумана/однотонных поверхностей и подготовка PSMT8. При неудачном
расширении большой составной текстуры доступна ограниченная повторная сборка
без одновременного хранения двух блоков пикселей.

Графика, физика, точность, форматы, Lua, UDMF, аддоны, сеть и прежние пределы
сохранены. Проверки выполнены в PCSX2 с 32 МиБ RAM: 13 пар игровых кадров
и 17 изображений GS совпали побайтно. Стресс-прогон MAP11 завершился без
замен текстур. FPS на настоящей PS2 не измерен; прежнее расхождение теста
outcode VU0 сохраняется.

Используйте существующие паки SRP2 v2 и `FINEACON.DAT`:

```sh
python3 -B tools/ps2/make_dist.py \
  --elf prebuilt/lossless-next7-20261114/SRB2-PS2-Hardware.ELF \
  --pak build/pak --out dist/SRB2-PS2 --zip
```

[Подробный отчёт](../../docs/PS2_OPTIMIZATION_NEXT7_20261114.md) содержит
измерения, расходы, ограничения и команды воспроизведения. Игровые ресурсы
и BIOS в поставку не включены. Предыдущие сборки сохранены отдельно.
