# SRB2 PS2 Hardware OPT17 — 2026-11-16

`SRB2-PS2-Hardware.ELF` собран из коммита `321c8d4da2cdc4d175271726b8b2bc450cbbc57b`: 607 production-файлов, 204 C units, две VU1-программы, обычные release/LTO флаги и прежние игровые системы. RNG в поставляемом ELF использует обычный OS seed. Диагностические копии с фиксированным seed не поставляются.

Размер ELF: **11 329 336 Б**. SHA256: `7bf67e21438e697cf40c112b9166c2a3018956fbe909ef34f0780de17750e96d`. `source-sha256.json` закрепляет все исходники; `build-report.json` — компилятор, реальные флаги и зависимости; `validation.json` — результаты и хеши публичных доказательств. Нужны совместимые игровые PAK и FINEACON.DAT.

Исправлены потеря владельца кэша геометрии при Hardware → Software → Hardware и освобождение отдельных CPU-буферов прозрачных вариантов flat-текстур. Сохранены исправления alpha, mip stride и состояния после перезапуска GS. Крупные текстуры и captures передаются частями через 16 КиБ постоянной VRAM, с временным расширением до 32 КиБ только в свободный соседний участок. CPU-кэш AP88 хранит точные индексы и coverage без полного POT-padding.

В `showmem` добавлены CPU/GPU~ **0–100%**. CPU измеряет foreground EE activity; GPU~ оценивает наблюдаемое submit-to-FINISH queue span, включая передачу/VU/задержку наблюдения. Это не точный аппаратный GS busy counter. В PAL логические 320×200 используют внутренний framebuffer 320×256; PCSX2 может показывать видеовыход 640×512.

Проверки стандартного PCSX2 с 32 МиБ:

- 30 полных пар кадров пяти сцен (default/full), loader hashes и настройки совпадают с базой `604cfd150`.
- MAP02 / 350 кадров: свободная Zone+C-heap RAM **+1 920 768 Б (1,83МиБ)**; Zone used/peak −1 974 592 Б. Пять потоков геометрии/материалов/качества совпадают.
- Восемь сценариев PAL/480p: 46 валидных captures, без аварий, ошибок heap и автоматического fallback. Включены переключения по 175 кадров, heat, wipes и их сочетание. Эти снимки проверяют завершение сценариев; сравнения с эталоном приведены отдельно.
- Все 34 стандартных GS readbacks точны; optional gap-layout PAK и TEXC дают по 3 точных кадра относительно штатных ресурсов.

Строгий набор **не весь зелёный**: сохраняются 400 диагностических строк о пропусках отрисовки в десяти default A/B запусках (по 40 на запуск, лог ограничивает их число), расхождение на 1 в одном RGB-канале одного пикселя в native fast-reference сравнении и прежний численный FAIL VU0 (CT32 55/56, CT16 50/51). C-heap peak +15 936 Б, C-free −12 864 Б и Zone arena −40 960 Б остаются отдельными strict FAIL. Допуски не менялись.

MAP11 по обычной эвристике переходит в Software; диагностический допуск за эту эвристику всё ещё вызывает реальный OOM guard 17 544 Б PU_RENDERWORK на первом кадре и безопасный переход в Software. Высокие разрешения с небом/жарой остаются тяжёлыми для CPU. Общая прибавка FPS, отсутствие fallback на всех картах и работа на физической PS2 не установлены.
