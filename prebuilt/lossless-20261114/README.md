# SRB2 PS2 — 2026-11-14

Готовые release-сборки из исходников
[`7de3fcfc8`](https://github.com/NeoniusNext/SRB2-Banpyura-PS2/commit/7de3fcfc8385547a1959ca80609fa4083249a231):

- [Software](SRB2-PS2-Software.ELF).
- [Hardware + Software](SRB2-PS2-Hardware.ELF).
- [SHA256SUMS](SHA256SUMS) и [результаты проверок](validation.json).

Сборки сохраняют полный набор возможностей порта, Lua, UDMF, аддоны, сеть,
форматы ресурсов и прежние пределы. Новый кеш заголовков спрайтов занимает
на 65 536 байт меньше RAM при прежней начальной ёмкости 8192 записи.
Ускорены точные вычисления NPOT-рендеринга и подготовка CT32-текстур.
Аудиокод побайтно совпадает с предыдущим проходом: два новых аудиоэксперимента
отклонены после замеров регрессий.

Используйте паки SRP2 v2 и `FINEACON.DAT` из рабочей раскладки порта.
Для упаковки выберите ELF и свой каталог паков:

```sh
python3 -B tools/ps2/make_dist.py \
  --elf prebuilt/lossless-20261114/SRB2-PS2-Hardware.ELF \
  --pak build/pak --out dist/SRB2-PS2 --zip
```

Подробные измерения, границы применимости и команды воспроизведения —
в [отчёте шестого прохода](../../docs/PS2_OPTIMIZATION_NEXT6_20261114.md).
Проверки выполнены в PCSX2 с 32 МиБ RAM; FPS на настоящей PS2 не измерен.
В стандартном тесте GS остаётся прежнее расхождение outcode VU0 при
совпадающих XYZ/Q. Игровые ресурсы и BIOS в эту поставку не входят.
