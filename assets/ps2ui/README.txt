pad_buttons_sheet.jpg - PlayStation controller button icons (Classic PS Select/Start, PS4 Share/Options, face buttons,
L1/L2/R1/R2, D-pad and stick variants, L3/R3, arrows), 1200x1200, white background (JPEG, no alpha).
Credit: "By: Max_the_Viking" (as printed on the sheet). Supplied by the project owner for use in the PS2 port UI.
Layout (grid, row by row from the top): Select, Start | PS4 Share, Options; Triangle, Square, Circle, Cross; L2, R2, L1, R1;
L stick, D-pad variants (down, left, right, up, left+right, up+down, all); R stick variants; L3 + L stick variants; R3, rotate L, rotate R;
arrows left, right, down, up.
The PS4 Share / Options strips on the sheet are NOT used by the port (no icon, no token, no name in the engine): the on-screen hints name only the DualShock 2 buttons.
The in-game icons (src/ps2/ps2_uiicons_data.inc) are redrawn as symmetric pixel art after this sheet (tools/ps2/ui_icons_pixel.py, ui_icons_build.py); the sheet is the reference for shapes and colours.
